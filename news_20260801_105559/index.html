什麼是 Token Saver？

Token Saver 是一款本地 MCP 伺服器，作為後台程式運行於用戶機器上，Claude 可以將其作為工具呼叫。其核心採用 Local Hybrid RAG 技術，允許用戶針對大型 PDF 提問，但永遠不需要將實際文件上傳給模型。

💡

Hybrid RAG 的運作原理

混合檢索結合兩種搜索方法：關鍵詞匹配（BM25）透過 SQLite FTS5 搜索找出精確術語，語義搜索（餘弦相似度）使用本地 all-MiniLM-L6-v2 嵌入模型理解問題含義。

⚠️

傳統方案的問題

以往使用 Claude 處理大型 PDF 文件時，需要將整份文件上傳，不僅消耗大量 Token 成本，更存在資料隱私風險。

📊

成本大幅降低

使用本地混合 RAG 僅傳遞相關段落給 LLM，Token 成本降幅高達 92% 至 99%。聊天越長，省費越多。

📌 重點提示

Token Saver 可為每個檢索區塊附上精確頁碼，用戶可即時打開本地 PDF 驗證 Claude 的聲明，確保回答的可追溯性與準確性。
