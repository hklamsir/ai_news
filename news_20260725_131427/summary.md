# AMD：AI運算重心轉向推論，蘇姿丰：CPU需求增速甚至超越GPU

## 📖 新聞導語

AMD 董事長暨執行長蘇姿丰在舊金山舉行的 AMD 年度 Advancing AI 活動中揭示：全球 AI 算力已有一半以上用於推論（Inference），代表 AI 正從模型訓練轉向實際部署階段。更值得關注的是，Agentic AI 的興起正在重新拉升 CPU 需求，其成長速度甚至超越 GPU。

## 💡 核心內容

### 🤖 AI從訓練轉向推論部署

蘇姿丰在主題演講中指出，AI 產業正迎來重要轉折點：全球 AI 運算首次有超過一半投入推論，而非模型訓練。她表示，生成式 AI 發展初期，市場競爭多集中在建立更大模型，但隨著企業開始大規模部署 AI 服務，推論已逐漸成為主要工作負載，代表 AI 正從研發階段走向實際應用。

### 🧠 Agentic AI重新定義CPU角色

Agent 與傳統聊天機器人的最大不同，在於 Agent 不只是回答問題，而是能持續執行一連串工作。一個 Agent 除了需要 GPU 完成模型推論，也需要 CPU 負責執行程式碼、管理記憶體與系統狀態、呼叫 API、存取資料庫，以及協調多個工具與工作流程。蘇姿丰表示，由於非推論的工作負載快速增加，使得 CPU 需求成長速度甚至超過 GPU。

### 🏗️ AMD三層AI資料中心架構

AMD 因應 Agent AI 帶來的新工作負載，提出三層 AI 資料中心架構：
- **第一層**：負責驅動 GPU 的 AI Host Node
- **第二層**：AMD 新增的 Agent Sandbox，負責執行 Agent、協調工具呼叫、管理工作流程與系統狀態
- **第三層**：企業既有的通用伺服器，執行資料庫及各類企業應用

對應這三類工作負載，AMD 在新一代 EPYC Venice 處理器推出三種版本：適合 GPU Host 的高時脈版本（128 核心）、針對 Agent 部署的 256 核心版本，以及針對企業應用的 128 核心版本。

### 💻 Helios機櫃：從晶片到系統

AMD 發表 Helios 機櫃，整合 MI455 GPU、EPYC Venice 處理器、Pensando 網路及 ROCm 軟體平台。Helios 並非 AMD 單方面完成後再交由客戶部署，而是在產品設計初期便與 OpenAI、Meta 及 Anthropic 等合作夥伴共同開發（co-develop）。蘇姿丰表示，未來 AI 資料中心的競爭，不只是比拚 GPU 效能，而是整體系統整合能力。

### 📈 2030年AI加速器市場上看1.4兆美元

蘇姿丰表示，AMD 與 OpenAI、Meta、Anthropic 等客戶討論後，看見 AI 應用型態的改變正重新推升 CPU 重要性。她在主題演說中提到，2030 年全球 AI 加速器市場規模將提高至 1.4 兆美元。企業如今利用 AI 追求的已不再只是成本降低，而是讓產品開發、企業流程與知識工作真正創造價值。

## 🔮 業界展望

AI 從模型訓練走向推論部署，是產業成熟的重要標誌。Agentic AI 的崛起則預示了下一波成長方向——不只是回答問題，而是能自主規劃、執行復雜任務的 AI 代理。這種轉變重新定義了資料中心的運算架構，CPU 的重要性被重新審視，而 AMD 提出的三層架構也反映了晶片廠商對未來 AI 基礎設施的佈局思路。
