# 对阿里新模型 Qwen3.8-Max 的真实评价。

## 📖 新聞導語

阿里巴巴發布 Qwen3.8-Max，一位 AI Maker 在真實任務場景中測試後，給出了令人信服的使用感受：國產模型與頭部閉源模型的差距已經非常小，他願意將 Qwen3.8-Max 作為主力模型使用。

## 💡 核心內容

### 測試者的核心觀點
作者批評了「國模與硅谷閉源模型不在一個梯隊」的慣性思維。他認為應該把國產模型和全球最強模型放在同一標準下比較，而非預設落後。從時間維度看，國產模型已從早年「不堪一擊」到現在「站穩腳跟」，在國際社區也贏得了尊重。

### Qwen3.8-Max 核心配置
| 參數 | 數值 |
|------|------|
| 總參數 | 2.4T（兆級） |
| 激活參數 | 95B |
| 架構 | 稀疏 MoE |
| 上下文 | 100 萬 Tokens |
| 多模態 | 原生支持 |

作者指出，2.4T 參數規模在國內僅有兩個模型達到，工程難度極高——從 200B 擴展到 300B 與從 2T 擴展到 3T，難度完全不在一個量級。

### 真實任務測試
作者分享了親測結果：
- **Coding 任務**：讓 AI 完成一個實際產品（App），包括找 Logo、二次加工、用戶名密碼兼容，跑了兩個多小時，一次性交出成品
- **辦公主務**：讓 AI 生成課件 PPT，AI 直接採用千問辦公主頁配色，最終成品「很有美感」
- **同事測試**：同樣讚賞效果

作者坦言：「 Coding 和工作任務，我願意把 Qwen3.8-Max 當成主力模型去用。」

### 為何今年是拐點
作者認為，不只是 Qwen3.8-Max，之前發布的 Kimi K3 以及後續將發布的國產模型，都說明國產模型與頭部閉源模型的差距已非常小。Sam Altman 也曾承認開源生態的價值——讓各國各行業不必完全依賴少數美國公司。

### 業界趨勢：Coding + 辦公
這次 Qwen 把辦公放到除 Coding 之外第二重要的位置。OpenAI 的 Codex、Anthropic 的 Claude Cowork 都在遷移到專業知識工作場景（文件處理、研究、分析、交付）。國產模型競爭也從 Coding 逐漸進入白領工作場景。

## 🔮 業界展望

作者從業者的視角觀察到一個心理轉變：兩年前討論國產模型問的是「能不能用、差距多大」，現在已經是「比較能力、價格性價比和真實任務完成效果」。這個變化來得比預期更快。
