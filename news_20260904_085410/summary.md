# 寫 Code 神器登場！Meta Muse Code 穩定版釋出：支援跨對話即時通訊與安全回退功能，完整功能看這裡

## 📖 新聞導語

Meta 旗下專為開發者打造的智慧程式碼工具「Muse Code」正式結束測試階段並邁入穩定版。本次重大升級大幅強化了大型多會話、多代理人（Multi-Agent）複雜軟體工程任務的處理能力，首度導入 CLI 跨對話即時通訊、靈活的子代理人協同工作流（Workflow），以及高安全性的對話回退機制。

## 💡 核心內容

### 跨對話即時訊息傳遞
Muse Code 穩定版新增「會話間訊息傳遞（Inter-session Messaging）」技術，打破傳統終端的資訊藩籬。當某個對話中的架構或程式碼變更可能影響另一個對話時，系統能主動發出跨會話警告；若某個會話成功解開其他會話正在卡關的相依性疑問，亦能自動將解答傳遞過去，大幅減少工程師在終端之間反覆切換的繁瑣負擔。

### 安全回退機制
當開發者在複雜的除錯或重構過程中發現方向偏差，只需在終端介面連續按下兩次 Esc 鍵，即可快速啟動回退機制。Muse Code 會嚴格限制僅能回退至系統預先標記的安全檢查點（Safe Checkpoints），並在執行任何復原或撤銷操作前要求工程師進行最終確認，有效防止意外覆蓋或工作進度遺失的風險。

### 多子代理人工作流
Muse Code 新增深度整合的「Workflow 工作流」架構。開發者只需在終端下達「使用工作流」指令，並將工作負載設定為「Ultra」超高模式，Muse Code 便會自動喚醒並編排大量專責子代理人（Sub-Agents）組成工程小隊，針對程式碼生成、單元測試、漏洞掃描與重構等工序進行高平行度協同作業，顯著縮短複雜架構任務的解決週期。

## 🔮 業界展望

伴隨穩定版的登場，Meta 同步揭曉三種靈活的付費訂閱方案，全面加速 AI 輔助軟體開發的落地進程。目前 macOS 與 Linux 平台使用者已可直接透過官方腳本完成終端安裝，並藉由 Meta Model API 帳戶即刻啟用。
