# Binance now lets AI agents trade, but keeping them in check is largely up to users | TechCrunch

## 📖 新聞導語

全球最大加密貨幣交易所 Binance 於週四推出「Agent OS」平台，讓 AI 代理程式能夠代替用戶分析市場並執行交易。這是首次有大型交易所將自主 AI 直接引入真實資金管理領域。

## 💡 核心內容

### Agent OS 平台功能
Binance 推出的 Agent OS 平台，讓開發者能夠將 AI 應用程式和代理程式連接到 Binance 的金融基礎設施。平台整合了 Binance 現有工具和服務，包括：
- Binance API
- Binance Wallet Agentic Hub
- Binance x402 交易驗證及支付 API
- Binance Skill Hub
- 新增的 Model Context Protocol（MCP）支援

### 支援的工具
平台支援多種主流 AI 開發工具：
- OpenAI 的 ChatGPT 和 Codex
- Anthropic 的 Claude Code
- Cursor

用戶可授權代理程式訪問市場數據、查看帳戶資訊及執行交易。

### 交易限額（Agentic Wallet）
與一般交易所交易不同，Binance 對 Agentic Wallet 交易設定了每日限額：
| 交易類型 | 每日限額 |
|---------|---------|
| 一般代幣兌換（Regular swaps） | $50,000 |
| DeFi 交易 | $100,000 |
| x402 支付 | $20 |

### 業界地位
Binance 擁有超過 3 億註冊用戶，是全球最大的加密貨幣交易所。Li 表示，Agent OS 是 Binance 協助開發者建立跨加密貨幣與傳統市場的 AI 應用程式的「第一步」。

競爭對手交易所亦已朝相同方向發展，利用 MCP 等開發者工具讓 AI 應用程式直接訪問市場數據和交易系統。

## 🔮 業界展望

業界觀察人士指出，Binance 此舉顯示大型加密貨幣交易所正積極搶佔 AI 代理交易市場。雖然平台設定了每日交易限額，但如何監管和確保 AI 代理的安全使用，仍主要由用戶自行負責。隨著 AI 技術在金融領域的應用加速，相關監管和安全措施將成為業界關注焦點。
