# AI Token 價格創新低，施壓 OpenAI 與 Anthropic

## 📖 新聞導語

AI 模型的 Token 價格創下歷史新低，關鍵市場基準於週一跌至每百萬 Token 97 美分，不足今年夏季峰值的一半。價格下滑令前沿模型公司面臨營收壓力，同時暴露了一個根本問題：現有供應可能已足以應付大多數任務。

## 💡 核心內容

### Token 價格基準跌至歷史低點
Silicon Data 指數追蹤百萬大語言模型 Token 的使用量加權有效價格，週一按週下跌 8.6%，跌至每百萬 Token 97 美分，不足夏季峰值的一半。

### 價格下跌驅動因素
- **中國開源模型崛起**：Moonshot 的 Kimi K3 等低成本模型壓低市場價格
- **OpenAI 降價**：7 月底調降兩個 GPT-5.6 模型的價格
- **動態定價普及**：前沿實驗室引入隨需求調整的動態定價機制
- **Token 生產成本下降**：進一步拉低市場價格

### 對前沿實驗室的影響
Syz Group 投資長 Charles-Henry Monchau 表示：「基礎模型實驗室是直接受影響者。Token 通縮壓縮營收線，而運算承諾仍然固定。」實驗室正將競爭焦點從模型純效能轉向分銷、記憶與上下文優勢。

### 市場信號
Silicon Data 研究主管 Steve Hou 指出，價格下跌可能顯示前沿與低成本模型的現有供應已足夠應付大多數任務。

## 🔮 業界展望

Token 價格持續下滑，對 OpenAI 與 Anthropic 等公司的營收構成壓力。開源模型的追趕意味著效能差距已縮短至數月，前沿實驗室需尋找新的差異化方向，包括 Agent 能力、上下文長度與企業整合。
